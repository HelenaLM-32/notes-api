PROYECTO DE PORTFOLIO · APLICACIÓN WEB

Un escritorio para tus notas.

Una pequeña aplicación de notas con aspecto de ordenador clásico. Puedes crear una cuenta, guardar tus ideas y volver a ellas cuando quieras.

Probar la demo →

¿Qué puedes hacer?

En el escritorio, abre Mis notas para ver tu carpeta. Desde ahí puedes crear notas, abrirlas en ventanas, cambiar su contenido y eliminarlas.

1

Crea una cuenta

Usa un correo de prueba y una contraseña de 8 caracteres o más. No utilices una contraseña que uses en otros sitios.

2

Abre tus notas

Haz clic en el icono Mis notas del escritorio o en la carpeta de la barra inferior.

3

Prueba las acciones

Crea una nota, ábrela para editarla, guárdala y, si quieres, elimínala.

Es una demo de portfolio: utiliza datos de prueba y no guardes información personal o sensible.

¿Qué significa CRUD?

CRUD es el nombre que damos a las cuatro acciones habituales para gestionar datos. En esta aplicación se aplican a tus notas:

C

Crear

Añadir una nota nueva.

R

Leer

Ver tus notas guardadas.

U

Actualizar

Cambiar el título o el texto.

D

Eliminar

Borrar una nota que ya no necesitas.

¿Cómo está construida?

La aplicación tiene dos partes que trabajan juntas: la interfaz que ves en el navegador y el servidor que valida las peticiones y guarda los datos.

INTERFAZ

HTML, CSS y JavaScript

HTML organiza la página, CSS dibuja el escritorio y JavaScript responde a los clics y se comunica con el servidor.

SERVIDOR

Node.js y Express

Recibe las peticiones de la interfaz, comprueba los datos y decide qué respuesta devolver.

DATOS

MongoDB y Mongoose

MongoDB guarda las cuentas y las notas. Mongoose define su forma y facilita consultarlas.

ACCESO

bcrypt y JWT

bcrypt protege las contraseñas guardando una huella que no se puede recuperar como texto. JWT permite reconocer una sesión iniciada.

Las notas están asociadas a su cuenta: el servidor solo devuelve las notas de la persona que ha iniciado sesión.

Un mapa sencillo del código

No hace falta entender todos los archivos de golpe. Este orden sigue el recorrido de una petición, desde que arranca el servidor hasta que aparece una nota en pantalla.

  1. src/server.jsArranca el servidor y conecta la base de datos.
  2. src/app.jsConfigura Express y conecta la web con las rutas de la API.
  3. src/routes/auth.jsRegistra cuentas e inicia y comprueba sesiones.
  4. src/routes/notes.jsContiene las operaciones para crear, listar, editar y borrar notas.
  5. src/middleware/auth.jsComprueba el token antes de permitir acceder a las notas.
  6. src/models/Define qué datos tiene una cuenta y qué datos tiene una nota.
  7. public/Contiene la pantalla, los estilos y el JavaScript del navegador.
Truco para seguir el flujo: en public/app.js busca la acción de la pantalla; después busca la ruta equivalente en src/routes/; por último mira el modelo en src/models/ para ver qué se guarda.
